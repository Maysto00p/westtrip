每日详细行程

D1 深圳 / 大连 → 成都

航班成都汇合
  • 2人从深圳、2人从大连分别出发，10月1日晚在成都汇合
  • 入住春熙路、太古里或天府广场附近
  • 如抵达时间允许，晚上逛春熙路、IFS、太古里

D2 成都 → 三星堆 → 九寨沟

博物馆高铁+大巴
  • 三星堆建议安排3－4小时
  • 重点：青铜大立人、青铜神树、黄金面具、纵目面具、文物修复馆
  • 三星堆站乘14:23或17:32目标车次至黄龙九寨站
  • 换乘大巴或酒店接送前往九寨沟口，入住沟口

D3 九寨沟深度游

全天景区观光车+步行
  • 尽早入园，按当天调度先到远端，再向下游览
  • 日则沟：箭竹海、熊猫海、五花海、珍珠滩瀑布
  • 则查洼沟：长海、五彩池
  • 树正沟：诺日朗瀑布、犀牛海、老虎海、树正群海
  • 晚上继续住九寨沟口

D4 九寨沟 → 黄龙 → 川主寺

联运巴士索道
  • 乘九寨沟至黄龙联运巴士
  • 省体力方案：上行索道、步行下山；体力好可全程步行
  • 重点：五彩池、黄龙寺、迎宾池、飞瀑流辉
  • 住川主寺镇或黄龙九寨站附近

D5 中查沟 + 松潘古城

慢旅行古城
  • 上午中查沟喝咖啡、看草甸与山景
  • 下午前往松潘古城，安排2－3小时
  • 古城墙、城门和街区漫步，住松潘古城

D6 松潘 → 成都 → 深圳 / 大连

高铁航班
  • 松潘站乘高铁返回成都
  • 如航班较晚，可寄存行李后安排人民公园、宽窄巷子或武侯祠
  • 4人分别飞回深圳和大连
