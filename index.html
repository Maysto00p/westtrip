每日详细行程

D1 深圳 / 大连 → 成都

航班成都汇合
  • 2人从深圳、2人从大连分别出发，10月1日晚在成都汇合
  • 入住春熙路、太古里或天府广场附近
  • 如抵达时间允许，晚上逛春熙路、IFS、太古里

D2 成都 → 三星堆 → 九寨沟

博物馆高铁+大巴
  • 三星堆建议安排3－4小时
  • 重点：青铜大立人、青铜神树、黄金面具、纵目面具、文物修复馆
  • 三星堆站乘14:23或17:32目标车次至黄龙九寨站
  • 换乘大巴或酒店接送前往九寨沟口，入住沟口

D3 九寨沟深度游

全天景区观光车+步行
  • 尽早入园，按当天调度先到远端，再向下游览
  • 日则沟：箭竹海、熊猫海、五花海、珍珠滩瀑布
  • 则查洼沟：长海、五彩池
  • 树正沟：诺日朗瀑布、犀牛海、老虎海、树正群海
  • 晚上继续住九寨沟口

D4 九寨沟 → 黄龙 → 川主寺

联运巴士索道
  • 乘九寨沟至黄龙联运巴士
  • 省体力方案：上行索道、步行下山；体力好可全程步行
  • 重点：五彩池、黄龙寺、迎宾池、飞瀑流辉
  • 住川主寺镇或黄龙九寨站附近

D5 中查沟 + 松潘古城

慢旅行古城
  • 上午中查沟喝咖啡、看草甸与山景
  • 下午前往松潘古城，安排2－3小时
  • 古城墙、城门和街区漫步，住松潘古城

D6 松潘 → 成都 → 深圳 / 大连

高铁航班
  • 松潘站乘高铁返回成都
  • 如航班较晚，可寄存行李后安排人民公园、宽窄巷子或武侯祠
  • 4人分别飞回深圳和大连

川西6日穿搭指南

边界说明：现在是2026年9月14日，10月1日至6日距离较远，逐日天气预报尚不稳定。以下为“可执行版”穿搭，出发前请按出发前3至5天的权威逐日预报微调。九寨沟国庆公开参考温度约白天15至20℃、夜间5至10℃，山区可能阴雨；松潘、黄龙海拔更高，需按更冷、更有风的条件准备。

核心策略：洋葱式分层

不要按6天带6套厚衣服，全程采用“洋葱式”分层，按需增减：

  • 内层：速干短袖或长袖
  • 中层：抓绒、针织衫或薄羽绒
  • 外层：防风防水冲锋衣
  • 下装：长裤为主，黄龙日用防风裤
  • 鞋：防滑、防泼水的运动鞋或徒步鞋

最稳妥的准备方式：按 5℃至20℃ 的跨度打包，并为黄龙单独准备更强的防风保暖组合。

D1 10.1 深圳/大连 → 成都

交通城区活动
  • 上身：短袖或薄长袖
  • 外套：轻薄夹克、针织开衫或薄风衣
  • 下身：长裤；鞋：舒适运动鞋
  • 随身：折叠雨衣或小型雨具
  • 深圳出发2人：把薄外套放随身行李最外层，到成都直接加上
  • 大连出发2人：可直接长袖加薄外套，热时脱下
  • 不建议：当天穿厚羽绒；穿不便走路的新鞋；把所有保暖衣物托运，至少随身带一层外套

D2 10.2 成都 → 三星堆 → 九寨沟

温差最大进山
  • 内层：速干长袖；中层：薄抓绒或薄针织衫（先放背包）
  • 外层：轻量冲锋衣，白天可不穿；下身：长款运动裤或薄软壳裤
  • 包内：薄羽绒、雨衣、帽子
  • 穿法节奏：成都/三星堆长袖单穿→高铁车厢加薄外套→黄龙九寨站出站加抓绒或薄羽绒→前往沟口大巴时冲锋衣放手边，不要压入行李箱底
  • 按“晚上到九寨沟”的条件准备，夜间可到5至10℃，长袖单层可能不够

D3 10.3 九寨沟深度游

全天户外叠穿
  • 公式：速干长袖 + 抓绒 + 防水冲锋衣 + 长裤 + 防滑徒步鞋
  • 清晨入园：三层全穿，怕冷加薄羽绒内胆，戴薄帽/冲锋衣帽、薄围巾或脖套
  • 中午徒步：出太阳先脱抓绒，保留速干层和冲锋衣，脱下中层放轻便背包
  • 下雨：穿冲锋衣或雨衣，背包加防雨罩，鞋底要有明显防滑纹，裤脚不宜太长避免吸水
  • 拍照配色：米白/奶咖/浅卡其配湖水森林；酒红/砖红更醒目；避免全身荧光色或大面积亮蓝色

D4 10.4 九寨沟 → 黄龙 → 川主寺

全程最暖高海拔/索道
  • 公式：速干保暖内层 + 抓绒 + 薄羽绒 + 防风防水冲锋衣
  • 下身：保暖打底裤 + 软壳裤或防风运动裤；不建议普通薄牛仔裤单穿
  • 配件：薄手套、保暖帽、脖套或围巾、墨镜、雨衣、防滑鞋
  • 关键：坐索道活动量低体感更冷；爬坡出汗要及时脱一层；不穿吸汗后难干的厚纯棉内衣；外层必须防风，厚毛衣不够
  • 拍照：米白、驼色、酒红、深绿外套出片；帽子兼顾保暖造型，但别为拍照穿不防滑的鞋

D5 10.5 中查沟 + 松潘古城

相对轻松昼夜温差
  • 内层：长袖T恤；中层：抓绒、卫衣或薄毛衣
  • 外层：冲锋衣或短款防风外套；下身：长裤；鞋：防滑运动鞋
  • 晚上：太阳落下及时加薄羽绒，不要等冷了才穿；手易冷带薄手套
  • 拍照配色：中查沟用米白/燕麦/浅棕；松潘古城用深红/藏蓝/墨绿；合照可统一“大地色”，但不要穿完全相同的衣服

D6 10.6 松潘 → 成都 → 深圳/大连

三种条件返程
  • 内层：短袖或薄长袖；中层：卫衣、针织衫或抓绒；外层：轻量冲锋衣
  • 下身：舒适长裤；鞋：运动鞋
  • 穿法节奏：松潘清晨三层穿齐→高铁内脱冲锋衣→成都活动保留薄长袖或中层→飞深圳外套随身落地收起→飞大连薄外套继续留手边

每人携带
  • 速干短袖或长袖：2至3件
  • 抓绒或薄卫衣：1件
  • 薄羽绒：1件
  • 防风防水冲锋衣：1件
  • 普通长裤：1条
  • 防风或软壳裤：1条
  • 保暖打底裤：1条

  • 快干袜：3至4双
  • 帽子、薄手套、脖套
  • 轻便雨衣
  • 墨镜和防晒用品
4人可共享
  • 鞋袜烘干用品
  • 少量暖宝宝
  • 备用雨衣
  • 衣物防水袋
  • 洗衣液或洗衣片

最简结论

  • 成都、三星堆：长袖 + 薄外套
  • 九寨沟：速干层 + 抓绒 + 冲锋衣
  • 黄龙：速干层 + 抓绒 + 薄羽绒 + 冲锋衣
  • 中查沟、松潘：白天三层灵活穿，晚上加薄羽绒
  • 全程：不带短裤，不穿不防滑的新鞋，雨衣放随身包、不放行李箱底

按5℃至20℃跨度打包，为黄龙单独准备更强的防风保暖组合；最终穿搭以出发前3至5天的权威逐日预报为准。
